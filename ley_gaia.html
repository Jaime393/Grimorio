🔬 Hallazgos Clave

✅
Señal GRACE real e independiente: El pico en 178.8 días (SNR=60, p=0.000) sobrevive la remoción completa de armónicos estacionales. No es el ciclo semianual astronómico disfrazado.
✅
Control solar pasado: Con 3,329 meses de manchas solares (la serie más larga del proyecto), el detector devuelve SNR=0.31. El ciclo hidrosférico de 178.8d no tiene origen solar directo.
❌
No aparece en atmósfera ni clima: CO₂ (818m), CH₄ (512m), temperatura Bogotá (822m) y temperatura global GISTEMP (1757m) muestran todos SNR < 1.5. La señal no se propaga al sistema climático acoplado.
⚠️
Hipótesis alternativa pendiente: El período orbital exacto de GRACE-FO es ~91 días. Un artefacto en 2×91 = 182d podría contaminar la banda. Se necesita verificar la fase orbital del satélite para descartarlo.

📐 Nota Epistémica

Lo que este análisis SÍ dice

  • Existe un ciclo real de ~178.8 días en las anomalías de agua terrestre global
  • Ese ciclo no es el semianual astronómico (test de remoción de armónicos)
  • Ese ciclo no tiene origen solar directo (control manchas, 3329 puntos)
  • El error respecto al target MIU (176d) es del 1.6% — dentro de la banda

Lo que este análisis NO dice

  • Que el ciclo GRACE sea causado por el campo ρ(x) del MIU
  • Que la Ley de Gaia opere a escala atmosférica, climática o de biodiversidad
  • Que 178.8d ≡ Ω_F/10 con certeza (es consistente, no confirmación)

El MIU-IFT v13.0 es un programa de investigación activo, no una teoría validada. Las predicciones falsables (DESI DR3, Euclid DR1, BepiColombo 2026-2028) están en 📚 Documentación.

🚀 Para Subir de EVIDENCIA_DEBIL → PARCIAL

1. GHCN global: Clima de múltiples estaciones del mundo (no solo Bogotá) → nodo Clima Global
2. GBIF global: Ocurrencias globales, no solo Colombia → de 73 a ~500 meses con cobertura real
3. Verificar fase orbital GRACE-FO: Descartar artefacto 2×91=182d comparando con ficheros de órbita JPL
4. PDO mensual + AMO mensual: Ciclos oceánicos de largo plazo → nodo Océano
5. PANGAEA.934337 (modelo de edad radiocarbónica Glen Carron) → nodo Paleoclima calibrado

💻 Código y Datos

El pipeline completo (Python, ~1,200 líneas) está disponible en el repositorio junto con los scripts peak_detector_v2.py, synthesis_v5.py y 11 módulos de análisis por nodo. Reproduce los resultados con:

pip install pandas numpy scipy matplotlib
python scripts/synthesis_v5.py

Fuentes de datos: GRACE JPL RL06.1M, GBIF API, NOAA/Scripps CO₂, NOAA/GML CH₄, SIDC manchas solares, GHCN-Daily, NASA GISTEMP v4.
