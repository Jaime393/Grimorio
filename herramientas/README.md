# Ecosistema MIU — Monismo Informacional Unificado

Un conjunto de herramientas de diagnóstico autocontenidas que miden la **coherencia informacional** de cualquier sistema usando la Ley Kᵢ.

---

## Cómo usar

1. Abre `index.html` en cualquier navegador moderno.
2. Elige una herramienta del catálogo.
3. Responde las 8 preguntas activando los toggles.
4. El campo se calcula automáticamente en tiempo real.

**No requiere internet. No requiere servidor. Todo funciona localmente.**

```
φ  = 1.6180339887498948482   (proporción áurea)

Kᵢ⁻ = φ × (D_f / 2.5) × (1 − 2f)         (coherencia negativa)
```
